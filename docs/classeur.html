Relie ton classeur

Tes cartes sont enregistrées dans un espace privé de ton compte GitHub, pour les retrouver sur tous tes appareils. Fais-le une seule fois par appareil.

  1. Crée ta clé d'accès sur GitHub. La case gist est déjà cochée. Choisis une durée, par exemple 1 an, puis clique sur Generate token.
  2. Sélectionne la clé affichée à la souris, du premier au dernier caractère, puis fais Ctrl+C. Le bouton de copie de GitHub ne fonctionne pas toujours ici.
  3. Colle-la ci-dessous. Elle commence par ghp_.
